## Architecture

- React 19 and Vite 8 PWA
- Clerk authentication, restricted by application code to `@iimsambalpur.ac.in`
- Supabase for Postgres, RLS/RPC access, realtime data, and Edge Functions
- Google Sheets schedule source exposed through Apps Script
- Vercel hosting, Sentry, and Vercel Analytics
- `schedule-app/src/App.jsx`: main shell, routing, and synchronization orchestration
- `schedule-app/src/components/`: feature UI
- `schedule-app/src/lib/`: data access and feature helpers
- `schedule-app/src/data/`: generated offline schedule snapshot and metadata
- `schedule-app/supabase/functions/`: backend Edge Functions

The build-time snapshot is generated by `scripts/generate-snapshot.mjs`. At runtime, the app refreshes the live Sheets feed and detects schedule changes. User state—including profiles, attendance, friends/groups, notifications, and push settings—syncs through Supabase.
